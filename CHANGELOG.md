## [0.1.0] - 2026-08-12

### Added

- Initial public open-source release under the MIT License.
- English-first documentation with complete Simplified Chinese entry points.
- Privacy-safe project website and interactive public demo using synthetic data only.
- Read-only IBKR synchronization, portfolio risk rules, decision support, review workflows, and operational safeguards.

### Security

- The public demo has no broker connection, API calls, database, cookies, or browser storage.
- Repository hygiene checks block common secrets, private runtime data, and accidental personal identifiers.
